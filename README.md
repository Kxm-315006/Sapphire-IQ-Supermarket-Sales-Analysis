# Sapphire IQ — Supermarket Sales Analysis

**Data Analytics Internship Project**

A dataset-driven Excel dashboard built from the original Sapphire IQ project brief and supplied supermarket sales workbook.

## Deliverables
- `output/Sapphire_IQ_Supermarket_Sales_Analysis.xlsx` — redesigned interactive Excel dashboard and supporting analysis.
- `data/source/BlinkIT_Grocery_Raw_Data.xlsx` — original dataset, preserved unchanged.
- `data/source/Sapphire_IQ_Project_Brief.pdf` — original project brief.
- `docs/` — analysis summary, methodology, and data dictionary.

## Workbook sheets
1. **Dashboard** — KPI cards, three dropdown filters, and four charts.
2. **Cleaned Data** — all 8,523 source records plus a standardized fat-content field.
3. **Analysis** — category/outlet/location summaries, category-by-outlet matrix, and statistical measures.
4. **Read Me** — dashboard usage and data-quality notes.

## Dashboard filters
Select Outlet Type, Location Tier, and Fat Content from the dropdowns on the Dashboard sheet. KPI cards and category sales chart respond to all three. Outlet type comparison and fat-content outlet comparison use the relevant filters for meaningful comparisons.

## Key dataset findings
- Total sales: **1,201,681.49**
- Average sales per record: **140.99**
- Top four category share: **50.60%**
- Highest sales category: **Fruits and Vegetables**
- Lowest sales category: **Seafood**
- Highest sales outlet type: **Supermarket Type1**
- Visibility-sales correlation: **-0.0013**

The source does not specify a currency. Missing item weights remain blank; original source labels are preserved. All findings are descriptive, not causal.
